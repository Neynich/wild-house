# WILD HOUSE — конструктор домов

Статический сайт без сборки: чистый HTML + CSS + JavaScript (без модулей и фреймворков).

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080      # затем http://localhost:8080
# или
npx serve .
```

Для 3D-графики подключается three.js r128 с CDN (cdnjs), шрифты Manrope и Unbounded — с Google Fonts.
Без интернета сайт работает в «лёгком» 3D-режиме (Canvas 2D).

## Структура

```
wild-house/
├── index.html                 разметка страницы (секции, модальные окна, панели)
├── assets/
│   ├── icons/                 иконка сайта: favicon, apple-touch-icon (180×180), 192/512, logo.jpg
│   ├── site.webmanifest       манифест для установки на домашний экран
│   └── img/
│       ├── models/            m0–m5.jpg — визуализации моделей домов
│       └── materials/         изображения материалов (brus, log, brick, …)
├── css/
│   ├── main.css               точка входа — подключает все файлы по порядку
│   ├── base/                  переменные, сброс, типографика, сетка
│   ├── components/            карточки, кнопки, формы, модалки, чат, 3D-тур, UI конструктора
│   ├── layout/                шапка, прогресс-навигация, подвал
│   └── sections/              hero, каталог, земля, конструктор, eco, faq
└── js/
    ├── boot.js                помечает страницу классом .js (грузится в <head>)
    ├── main.js                запуск и цикл отрисовки
    ├── core/                  утилиты, localStorage, заглушка THREE
    ├── data/                  данные: модели, материалы, стили, пути к картинкам
    ├── three/                 3D-примитивы, геометрия домов, сборка мешей
    ├── scenes/                сцены: hero, конструктор, небо, мир, участок, камера, лёгкий режим
    ├── builder/               расстановка объектов, взаимодействие, цвета, ограждение
    ├── features/              каталог, материалы, земля, AI-дизайн, кабинет, чат, ECO, заявки
    ├── ui/                    уведомления, панель объекта, эффекты
    └── tour/                  3D-прогулка внутри дома
```

## Иконка и Telegram

- Иконка домашнего экрана iPhone/iPad — `assets/icons/apple-touch-icon.png`; чтобы заменить, подставьте новый PNG 180×180 с тем же именем.
- Telegram-канал: `https://t.me/wildhousee` — иконка в шапке и карточка в секции «Контакты» (`css/components/telegram.css`).

## Важно

- **Порядок подключения скриптов в `index.html` менять нельзя.** Файлы используют общие
  глобальные переменные (`T`, `$`, `items`, `TYPES` и др.), как и в исходном едином скрипте.
- **Порядок CSS в `css/main.css` тоже важен:** поздние файлы переопределяют ранние.
- Ссылка `SITE` в `js/features/share-autosave.js` ведёт на старый адрес артефакта —
  замените её на адрес вашего сайта, чтобы функция «Поделиться» вела на него.
- AI-дизайн использует `window.claude` (доступен только внутри Claude). Вне него
  автоматически включается встроенный запасной генератор.
